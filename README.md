# PARALLAX World Guide

GitHub Pages에 바로 올릴 수 있는 정적 웹사이트입니다.

## 구조
- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/`

## 배포
1. GitHub 저장소 생성
2. 파일 전체 업로드
3. Settings → Pages
4. Deploy from a branch 선택
5. `main` / root 선택

## 공개 정보 기준
이 버전은 유저 공개용입니다.
- 특정 비밀 인물의 정체·과거·관계·동기 미수록
- 대홍수의 상세 전말 미수록
- 해금 전 기밀 미수록
